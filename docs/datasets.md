# Datasets

Three datasets feed different parts of this project. None are committed to
source control (too large) — see download/extraction steps below.

## 1. KonIQ-10k

**Used for:** Suitability model training — the source of "generic" images
(6 non-occlusion defects injected synthetically).

- Location: `koniq10k_512x384/512x384/` (flat folder of `.jpg` files)
- Native resolution: 512×384 (fixed) — **important**: this is already below
  the API's default 640×480 minimum-resolution threshold. If you ever add a
  detector feature computed on raw pixel dimensions, check whether KonIQ's
  fixed size gives it any real variance (see the Resolution note in
  `docs/decisions.md` for a case where this was exactly the bug).
- Almost never contains a face — this is *why* it's the generic-defect
  source and not the occlusion source: `ModelOcclusionDetector` is
  face-gated, so most KonIQ images have nothing for it to detect.

## 2. COFW (Caltech Occluded Faces in the Wild)

**Used for:** (a) fine-tuning the occlusion classifier, (b) real occlusion
labels for the Suitability model's training set.

- Source files: `COFW_train_color.mat`, `COFW_test_color.mat` (MATLAB v7.3/HDF5)
- Contains 29 facial landmarks per face, each with an occlusion bit
  (0=visible, 1=occluded) — this is genuine hand/hair/object occlusion
  ground truth, not a synthetic overlay.
- **Caveat:** in the training split, the first 845 images are LFPW
  (unoccluded) and only the remaining ~500 are genuine COFW (occluded) —
  skews class balance toward "clean" in that split specifically.

### Extraction

`scripts/extract_cofw.py` reads both `.mat` files (tries `scipy.io.loadmat`
first, falls back to `h5py` for v7.3 files) and writes:

```
data/cofw_extracted/
├── images/{train,test}/*.jpg
└── labels.csv   # image_path, split, bbox_x/y/w/h, occluded_landmark_ratio, is_occluded
```

Actual extraction counts (confirmed run): **1345 train / 507 test** images,
matching COFW's known official counts.

Occlusion severity tiers, derived from `occluded_landmark_ratio` (used by
the Suitability dataset generator, see `scripts/synthetic_augmentation.py`):

| Ratio | Severity |
|---|---|
| 0.0 | none |
| < 0.15 | low |
| < 0.35 | medium |
| ≥ 0.35 | high |

Label distribution at the default `is_occluded` threshold (0.15):
train 998 clean / 347 occluded; test 200 clean / 307 occluded (COFW's test
split is deliberately occlusion-heavy — it's the hard benchmark).

## 3. Suitability model training set (synthetic + real)

**Generated by:** `scripts/generate_training_dataset.py`

Combines both sources above:

- **KonIQ-10k** → 6 non-occlusion defects (blur, darkness, overexposure,
  glare, motion, resolution) injected synthetically at severity none/low/
  medium/high (`scripts/synthetic_augmentation.py`). Occlusion severity is
  always "none" for this source.
- **COFW** → real occlusion severity (from `occluded_landmark_ratio`,
  above) PLUS the same 6 synthetic defects layered on top, so occlusion
  co-occurs with other degradations in training too.

Each row = one image variant: features (from `FeatureExtractor`, i.e. the
real detector outputs) + `severity_<defect>` columns (ground truth, not fed
to the model) + `suitable` label.

**Label rule:** NOT suitable if any defect is "high" severity, OR if 2+
defects are "medium" severity. This rule is intentionally independent of
the detectors' own outputs — it comes from the *injected* severity, not
from what the detectors say, to avoid circular/self-referential training
(see `docs/decisions.md`).

First generated run (7 pre-framing features): 1500 KonIQ base images × 2
variants + 1000 COFW images, seed=42 → **4000 rows total, 1435 suitable /
2565 not suitable**. Regenerated later with the framing feature included —
see `models/suitability_model_metadata.json` for the current run's exact
counts and split sizes.

## Reproducing from scratch

```bash
# 1. COFW extraction
python scripts/extract_cofw.py \
  --train-mat COFW_color/COFW_train_color.mat \
  --test-mat COFW_color/COFW_test_color.mat \
  --output-dir data/cofw_extracted

# 2. Suitability training set
python scripts/generate_training_dataset.py \
  --koniq-dir koniq10k_512x384/512x384 \
  --cofw-labels-csv data/cofw_extracted/labels.csv \
  --occlusion-onnx models/face_occlusion_finetuned.onnx \
  --face-detector-onnx models/face_detection_yunet_2023mar.onnx \
  --output-csv data/suitability_training.csv \
  --koniq-base-count 1500 --koniq-variants-per-image 2 \
  --cofw-count 1000 --seed 42

# 3. Train
python scripts/train_suitability_model.py \
  --training-csv data/suitability_training.csv \
  --output-dir models/
```
